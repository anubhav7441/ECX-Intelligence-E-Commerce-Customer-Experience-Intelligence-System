How reliable is this?

Complaint classifier (150 reviews, single annotator): micro-F1 {{ '%.2f'|format(ev.micro_f1) }}, exact-match {{ '%.0f'|format(ev.exact_match_accuracy*100) }}%. Detecting "has any complaint": F1 {{ '%.2f'|format(ev.complaint_vs_no_complaint.f1) }}.

Sentiment model (labels derived from stars, 3 classes): accuracy {{ '%.1f'|format(nlp.sentiment.tfidf_lr.accuracy*100) }}%, macro-F1 {{ '%.2f'|format(nlp.sentiment.tfidf_lr.macro_f1) }} vs lexicon baseline {{ '%.2f'|format(nlp.sentiment.lexicon_baseline.macro_f1) }} and majority-class accuracy {{ '%.1f'|format(nlp.sentiment.majority_baseline.accuracy*100) }}%. Neutral (3-star) is hard: F1 {{ '%.2f'|format(nlp.sentiment.tfidf_lr.per_class.neutral['f1-score']) }}.

Weakest categories: seller issue and wrong product (see F1 table). Treat complaint counts as indicative.

Labels for the 150-review evaluation sample were assigned by one annotator (an AI assistant), blind to the classifier output and star score; they are not independent human gold labels. The labelled CSV ships with the project so it can be audited.
